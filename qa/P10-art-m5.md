## 物理模型（单位：m=g=P=L=1，L 为梯长）
约定：墙在右（x=0 处墙面），梯底在左；θ 为梯与地面夹角；底端外滑（向左）时地面摩擦指向 +x，记 σ=+1，反之为 -1；墙面对梯子的支持力 N_w 指向 -x。

贴墙阶段未知量 θ̈、N_w、N_f，牛顿–欧拉方程：
- x：`½(sθ̈ + cω²) = -N_w + σμN_f`
- y：`½(cθ̈ - sω²) = N_f - 1`
- 绕质心：`(1/12)θ̈ = ½(σμ s - c)N_f + ½ s N_w`

用 Cramer 法则解 3×3，取 `σ = (ω < 0 ? +1 : -1)`（静止/反向时按准静态取号）。静平衡解退化为 `N_w = f = P/(2tanθ)`、`tanθ_min = 1/(2μ)`，与旧代码一致。

### 与任务书的两处偏差（重要）
1. **转动惯量取 `I_CM = 1/12`，不是 1/3。** 任务书写的 `I = mL²/3` 是“绕一端”的值；本模型以质心写转动方程，必须用 `1/12`。贴墙滑动时广义惯量为 `I_CM + m(L/2)² = 1/3`，所以无摩擦极限下的 `θ̈ = -1.5cosθ` 与解析解完全一致（见验证表 FRIC0）。
2. **离墙后不采用“绕固定底端转动”。** 底端在墙的左侧，若把底端钉死再减小 θ，顶端会向右移动、穿进墙里（几何上必然穿墙，与“离开墙面”矛盾）。改为物理正确的“顶端自由、底端仍在地面上滑动”的两自由度模型：未知量 α、N_f（`N_w = 0`），随后回代底端加速度 a_B：
   - `½(cα - sω²) = N_f - 1`
   - `(1/12)α = ½(σμ s - c)N_f`
   - `a_B = ½(sα + cω²) + σμN_f`
   状态量 (θ, ω, x_B, ẋ_B) 用 RK4 同步积分；离墙瞬间取 `ẋ_B = sinθ·ω`，与贴墙约束连续，α 也连续（实测跳变 <0.01 rad/s²）。另加 0.2 s⁻¹ 的角速度轻阻尼（残余滚阻/数值稳定，量级远小于库仑摩擦耗散）。
   分离判据：贴墙阶段出现 `N_w < 0` 即切换，并记录 `sepTh`、`sepBaseU = cos(sepTh)`；渲染时 `x_base = wallX - L·sepBaseU + x_B·L`。

## 遗留风险
- 落地判定为 θ ≤ 0.05 rad，落地瞬间直接把 ω 置 0，未建模与地面的碰撞/反弹。
- 分离用单步 `N_w<0` 判定，分离角对 μ 与初值有 ~0.2° 量级离散误差。
- 若用探针强行从“高于临界角”的初值启动滑动（正常交互不会发生），高 μ 下会出现能量增长；正常路径（θ < θ_min 或 URL 初值低于临界角）不会触发。
- 分离后底端若出现 N_f<0（本参数范围未出现），未实现离地腾空。
- 数值均为无量纲演示单位；μ=0 时摩擦为零，与“打滑”直觉一致但没有静摩擦保持。
