# 比奈方程 · 行星运动

> 从牛顿第二定律的极坐标形式出发，引入 \(u=1/r\) 推导比奈方程，并通过修改源项的 \(\lambda u^2\)、\(\mu u^3\) 修正项，数值展示轨道进动（含唯象的水星近日点进动演示）。

> 模块代号：00-binet · 理论力学 · 交互讲义

## 覆盖内容

- 比奈方程：\(d^2u/d\theta^2 + u = C + \lambda u^2 + \mu u^3\)（\(u=1/r\)）
- 牛顿引力（\(\lambda=\mu=0\)）下的闭合圆锥曲线轨道
- 二次修正 \(\lambda u^2\) 与三次修正 \(\mu u^3\) 引起的近心点进动
- 三维视角下的轨道可视化与等比缩放

## 物理模型

无量纲约定：\(G=M=1,\ h=L/m=1\)（于是 \(C=GM/h^2=1\)），\(C=GMm^2/L^2\)。比奈方程

\[
\frac{d^2u}{d\theta^2}+u = C+\lambda u^2+\mu u^3,\qquad u=1/r.
\]

当 \(\lambda=\mu=0\) 回到牛顿引力，轨道为闭合圆锥曲线；修正项不为零时近心点随每圈转动形成进动。RK4 固定步长积分，轨迹在三维视图中绘制。

## 参数说明

| 参数 | 物理含义 | 默认值 | 范围 | 单位 |
|---|---|---|---|---|
| C | 中心引力强度（\(GMm^2/L^2\)） | 1.00 | 0.25-2.5 | 无量纲 |
| e | 初始偏心率 | 0.60 | 0-0.95 | 无量纲 |
| λ | 二次修正系数 | 0.0000 | -0.06-0.06 | 无量纲 |
| μ | 三次修正系数（唯象进动） | 0.0000 | -0.006-0.012 | 无量纲 |
| 速度 | 动画速度倍率 | 1.0 | 0.1-3 | 倍 |
| 缩放 | 视图缩放 | 1.00 | 0.2-3 | 倍 |

## 预设

| 预设 | λ | μ | 说明 |
|---|---|---|---|

| 相对论进动（μ > 0） | 0 | >0 | 近心点每圈进动 |

## 已知限制

- 无 selftest 契约（M0 结构性限制）。
- \(\mu u^3\) 项为唯象进动，幅度远大于水星实际 \(5.02\times10^{-7}\,\mathrm{rad/orbit}\)；严格 GR 修正应为 \(\lambda u^2\) 项（\(\lambda_{\rm GR}=3GM/c^2\)），见 `binet.tex`。
- 单位取 \(G=M=1,\ h=L/m=1\) 为无量纲演示；真实物理需恢复 \(G,M,L\)。
- 三维视图超出视野时需手动调小缩放。
- 不含相对论严格推导（见 binet.pdf）。
