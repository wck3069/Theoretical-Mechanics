公式取自《理论力学》第6章手稿：p_a = L_{q̇_a}，H = Σp_a v_a − L（速度已消去，不是独立变量）； 恒等有 H_{p_a} = v_a、H_{q_a} = −L_{q_a}，最后才在真实路径上得正则方程 q̇ = H_p、ṗ = −H_q。 拉格朗日型罗斯函数 R(x, y, ẋ, μ) = L − Σμ_α ẏ_α（另一些文献取相反号 R_H = −R，勿混用）； θ 循环时 μ = p_θ 才可固定为常数。平面中心力约化：R = (m/2)ṙ² − [V + ℓ²/(2mr²)]， 离心项符号来自固定动量的变分问题，故 m r̈ = −V′ + ℓ²/(mr³)。单位制 m = l = g = k = 1。
