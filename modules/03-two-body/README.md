## 物理模型

两体系统：质量 M1（恒星）、M2（行星），间距 a。质心条件 M1 r1 = M2 r2，r1+r2=a。

r1 = M2/(M1+M2) · a
r2 = M1/(M1+M2) · a

约化质量 μ = M1 M2/(M1+M2)。两体 Kepler 第三定律：ω² = G(M1+M2)/a³。

摆动速度 v1 = ω r1。多普勒频移 Δλ/λ = v/c。

无量纲单位：M☉=1、AU=1、yr=1，G=4π²。太阳-木星：M2=0.000954 M☉、a=5.20 AU。太阳-地球：M2=0.000003 M☉、a=1.00 AU。

### 有量纲示例

太阳-木星系统：M☉=1.989×10³⁰ kg，MJ=1.898×10²⁷ kg，aJ=7.78×10¹¹ m。质心距离 r1=MJ/(M☉+MJ)·aJ≈7.42×10⁸ m≈1.07 R☉。角速度 ω=2π/PJ≈1.68×10⁻⁸ rad/s。摆动速度 v1=ωr1≈12.5 m/s。多普勒位移 Δλ=500 nm×12.5/(3×10⁸)≈2.08×10⁻⁵ nm。
