重陀螺的进动与章动

模块 21 · 第 5 章 刚体力学 · 重对称陀螺 · 有效势 V_eff(θ)

支点在下方、质心高 l 的对称陀螺：循环动量 p_φ（竖直角动量 L_z）与 p_ψ=I₃ω₃（轴向角动量）把三维运动约化成倾角 θ 的一维有效势问题。轴尖在单位球面上画出进动 + 章动玫瑰线。拖动画布旋转视角；切到「有效势」看转折点与极小，切到「睡眠陀螺」扫过稳定阈值 ω₃c=√(4I₁Mgl)/I₃。

欧拉角（θ 章动 / φ 进动 / ψ 自转）
p_ψ = I₃(ψ̇ + φ̇cosθ) = I₃ω₃ = L₃
p_φ = I₁φ̇sin²θ + p_ψcosθ = L_z
½I₁θ̇² + V_eff(θ) = E − p_ψ²/(2I₃)
V_eff = (p_φ − p_ψcosθ)²/(2I₁sin²θ) + Mgl·cosθ
稳恒进动 I₁Ω²cosθ₀ − I₃ω₃Ω + Mgl = 0
一维约化（Routh 固定 p_φ、p_ψ）
I₁θ̈ = −V_eff′(θ)，转折点 V_eff = E′
极小 θ*（稳恒支） V_eff′(θ*) = 0，极大点不稳定
章动频率 ω_n = √(V_eff″(θ*)/I₁) = √((h/I₁ − 2Ωcosθ₀)² + Ω²sin²θ₀)
θ=0 奇异 → 线性化偏移 (u,v)
I₁ü + h·v̇ − Mgl·u = 0，　I₁v̈ − h·u̇ − Mgl·v = 0
σ± = i(h ± √(h² − 4I₁Mgl))/(2I₁)，　h = I₃ω₃
稳定判据 ω₃² > 4I₁Mgl/I₃²（失稳时 σ 有正实部：指数增长；临界重根扰动 ∝ t）
