第 4 页

3.1 费马原理（1662年，法国科学家提出） 交互演示

费马原理指出，光沿着两点之间所需光程最短的路径前进。也就是说，光从$a$到$b$选择走一条用时最短（或最长）的路径。

光在折射率为 $n(x,y,z) = n(\vec{r})$ 的介质中运行，光传播$ds$路程所需的时间为

\[ dt = \frac{ds}{c/n(\vec{r})} \]

从$a$点到$b$点，传播的路径 $S = \int_a^b ds$

\[ t = \int dt = \frac{1}{c}\int_a^b n(\vec{r}) ds, \]

最终光程所需的时间依赖于路径的选取，原则上光传播有无穷个路径，但物理发生的过程必定是由$a$到$b$，所耗用的时间最小。

这就引入一个问题，怎么求 $t$ 的最小值，求解这一问题可用变分法或泛函数分析。

3.2 变分法计算 交互演示

一般的变分法，是1750年代法国数学家拉格朗日（Lagrange）和瑞士数学家欧拉（Euler）首先发展完善的，比费马原理的提出，晚了一个世纪。

在直角坐标系中 $ds = \sqrt{dx^2 + dy^2}$

所以

\[ \begin{aligned} t &= \frac{1}{c}\int n(x) \sqrt{dx^2 + dy^2} = \frac{1}{c}\int n(x) \sqrt{1 + \left( \frac{dy}{dx} \right)^2} \cdot dx \\ &= \frac{1}{c} \int n(x) \sqrt{1+(y')^2} dx \end{aligned} \]

第 5 页

在这里, 我们看到 $t$ 的值依赖于 $x$, 和 $y'(x)$. 当然 $n(x)$, 有可能也依赖 $y$. 所以我们写为

\[ t = \frac{1}{c} \int n(x,y) \sqrt{1+(y')^2} dx = \int F(x, y(x), y'(x)) dx \]

被积函数 $F(x, y(x), y'(x)) = \frac{n(x,y)}{c} \sqrt{1+(y')^2}$, 是 $x, y(x)$ 和 $y'(x)$ 的函数.

我们要求解的问题. 怎么找到 $y(x)$ 使得 $t$ 最小?

更为一般的情况. Euler-Lagrange 求解任意函数的极小值.

\[ I = \int F(x, y(x), y'(x)) dx \]

$I$ 的极值, 以及对应的 $y(x)$

所谓的极值, 是指积分值 $I$ 是一个稳定点. 当我们改变 $x, y(x), y'(x)$ 时, 积分值 $I$ 不变. 我们看当 $x$ 有一个无穷小变化 $x \to x+\delta x$

$x$ 的函数 $f(x) \to f(x+\delta x) = f(x) + \frac{\partial f}{\partial x} \cdot \delta x + \frac{1}{2!} \frac{\partial^2 f}{\partial x^2} (\delta x)^2$

稳定点的意义是指 $\frac{\partial f}{\partial x} = 0$

对于一个多变量函数

\[ f(x_1, x_2) \longrightarrow f(x_1+\delta x_1, x_2+\delta x_2) = f(x_1, x_2) + \sum_{i=1}^2 \frac{\partial f}{\partial x_i} \delta x_i + \sum_{i=1}^2 \sum_{j=1}^2 \frac{\partial^2 f}{\partial x_i \partial x_j} \delta x_i \delta x_j + \cdots \]

极值要求 $\frac{\partial f}{\partial x_1} = 0$ 和 $\frac{\partial f}{\partial x_2} = 0$.

以此类推至更多自变量的情况.

第 6 页

总结：当我们要 $f(x)$ 极值时

\[ \delta f = f(x_i + \delta x_i) - f(x_i) = 0 \quad \text{保留到} \ \delta x_i: \text{第一阶} \]

因 $\delta x_i$ 表示任意变化，上式可得 $\frac{\partial f}{\partial x_i} \delta x_i = 0 \implies \frac{\partial f}{\partial x_i} = 0$

我们再回头看 $I$，$I$并不是一个常规函数，

常规函数指：数 $\xrightarrow{f}$ 数的映射

而 $I$ 是可能的路径，或可能的函数 $y(x)$ 的函数，而 $y(x)$ 是未知的，$I$ 是 $y(x)$ 在整个路径的依赖。

\[ I\left[ y(x) \right] = \int_{a}^{b} F\left(x, y(x), y'(x)\right) dx \]

方括号表示 $I$ 不是通常意义下的函数。

$I\left[ y(x) \right]$ 指泛函（functional），通常人们称其为函数的函数，

泛函可以依赖于多个函数，我们先看最简单的情况 $I\left[ y(x) \right]$

当函数 $y(x)$ 变化时，我们计算 $y(x) \to y(x) + \underbrace{\delta y(x)}_{\text{路径偏移}}$

因为初始点 $a$ 和终止点 $b$ 固定，所以 $\delta y(a) = 0 \quad \delta y(b) = 0$

边界点没有微扰。

我们希望

\[ \delta I\left[ y(x) \right] = I\left[ y(x) + \delta y(x) \right] - I\left[ y(x) \right] = 0 \]

泛函 $I$ 取极值对应于：泛函的微扰变化为0（$\delta y(x)$ 的第一阶）

怎么计算 $I\left[ y(x) + \delta y(x) \right]$？

第 7 页

我们把对 $x$ 的连续积分离散化。

\[ a < x < b \implies x_n = a + n\varepsilon, \quad \varepsilon \geq 0, \quad 0 < n < \frac{b-a}{\varepsilon} \]

当 $\varepsilon \to 0$ 时，离散点变连续。

然后 泛函指它是 $y(x_0), y(x_1) \cdots y(x_{n-1}), y(x_n)$ 无穷个变量的函数

当 $\varepsilon \to 0$ 时 $I[y(x)]$ 为无穷个自变量的函数

\[ I = \int F(x, y(x), y'(x)) dx \implies I = \sum_{n} F(x_n, y(x_n), y'(x_n)) \varepsilon \]

当我们改变 $y$ 时，$y(x_n) \to y(x_n) + \delta y(x_n)$，

$y'(x)$ 也相应改变 $y'(x_n) \to y'(x_n) + \delta y'(x_n)$，

\[ y' = \frac{dy}{dx} = \frac{y(x_n) - y(x_{n-1})}{\varepsilon} \]
\[ \delta y'(x_n) = \frac{\delta y(x_n) - \delta y(x_{n-1})}{\varepsilon} = \frac{d \delta y(x)}{dx}, \quad \delta \frac{dy}{dx} = \frac{d}{dx} \delta y \]

所以

\[ \delta I = \sum_{n} \left[ \frac{\partial F}{\partial y(x_n)} \delta y(x_n) + \frac{\partial F}{\partial y'(x_n)} \delta y'(x_n) \right] \varepsilon = 0 \]

当 $\varepsilon \to 0$ 时

\[ \delta I = \int_a^b \left[ \frac{\partial F}{\partial y(x)} \delta y(x) + \frac{\partial F}{\partial y'(x)} \frac{d}{dx} \delta y(x) \right] dx \]

对上式第二部分 分部积分

\[ \int f \frac{dg}{dx} dx = \int d(fg) - \int g \frac{df}{dx} dx \]
\[ \int \frac{\partial F}{\partial y'(x)} \frac{d}{dx} \delta y(x) dx = \int d\left( \frac{\partial F}{\partial y'(x)} \delta y(x) \right) - \int \left( \frac{d}{dx} \left( \frac{\partial F}{\partial y'(x)} \right) \right) \delta y(x) dx \]
\[ \int_a^b d\left[ \frac{\partial F}{\partial y'(x)} \delta y(x) \right] = \left. \frac{\partial F}{\partial y'(x)} \delta y(x) \right|_a^b = 0 \]

因为在边界点没有扰动

第 8 页

所以我们有

\[ \delta I[y(x)] = \int_a^b \left( \frac{\partial F}{\partial y(x)} - \frac{d}{dx}\left[ \frac{\partial F}{\partial y'(x)} \right] \right) \delta y(x) dx = 0 \]

因为 $\delta(y(x))$ 代表任意变化。

若 $\frac{\partial F}{\partial y(x)} - \frac{d}{dx}\left[ \frac{\partial F}{\partial y'(x)} \right]$ 在某一段 $x$ 的区间不为0，则我们可以找 $\delta y(x)$ 的扰动，使得 $\delta I[y(x)] \neq 0$。

若想 $\delta I[y(x)] = 0$，必有

\[ \frac{\partial F}{\partial y(x)} - \frac{d}{dx}\left[ \frac{\partial F}{\partial y'(x)} \right] = 0 \quad \text{欧拉方程}. \]

例 光在真空中传播 $t \propto S$，$t$ 最小，等价于 $S$ 最小，求传播路径

\[ S = \int_a^b ds = \int_a^b \sqrt{dx^2 + dy^2} = \int_a^b \sqrt{1 + (y')^2} dx \]

代入欧拉方程 $F(x, y, y') = \sqrt{1 + (y')^2}$

\[ \frac{d}{dx} \frac{\partial F}{\partial y'(x)} = \frac{d}{dx} \frac{y'}{\sqrt{1 + (y')^2}} = 0 \]

即

\[ \frac{y'}{\sqrt{1 + (y')^2}} = k \implies y' = \frac{\pm k}{\sqrt{1 - k^2}} \equiv C \ (\text{常数}) \]
\[ \frac{dy}{dx} = C \implies y = C x + d \]

其中 $(C, d)$ 可由初末两点定出，$C$ 为常数，$d$ 为常数。

即由费马原理推导出了光沿直线传播。

第 9 页

1.

假设介质折射率为 $n = \frac{y_0}{y}$，求光在介质中传播的轨迹。

解：根据费马原理，

\[ I[x] = \int \frac{ds}{c/n} = \frac{1}{c} \int \frac{y_0}{y} \sqrt{(dx)^2 + (dy)^2} = \frac{y_0}{c} \int \frac{1}{y} \sqrt{1 + (x')^2} dy \]

其中 $x' = \frac{dx}{dy}$，令 $F = \frac{1}{y} \sqrt{1 + (x')^2} = F(y, x, x')$。

运用欧拉公式可得：

\[ \frac{\partial F}{\partial x} - \frac{d}{dy} \frac{\partial F}{\partial x'} = 0 \]

因 $\frac{\partial F}{\partial x} = 0$，得

\[ \frac{\partial F}{\partial x'} = \frac{x'}{y \sqrt{1 + (x')^2}} = k \]

$k$ 为常数，解得

\[ x' = \pm \frac{k y}{\sqrt{1 - k^2 y^2}} \]

积分得

\[ x - x_0 = -\frac{\sqrt{1 - k^2 y^2}}{k} \]

整理得

\[ k^2 (x - x_0)^2 + k^2 y^2 = 1 \]

设 $y = \frac{1}{k} \sin\theta$，则 $dy = \frac{1}{k} \cos\theta d\theta$，

\[ \frac{dx}{dy} = \frac{dx}{d\theta} \cdot \frac{d\theta}{dy} = \frac{dx}{d\theta} \cdot \frac{k}{\cos\theta} = \pm \frac{k \sin\theta}{\sqrt{1 - \sin^2\theta}} = \pm \frac{\sin\theta}{\cos\theta} \]

故

\[ \frac{dx}{d\theta} = \pm \frac{1}{k} \sin\theta \]

积分得

\[ x - x_0 = \pm \frac{1}{k} \cos\theta \]

结合 $y = \frac{1}{k} \sin\theta$，仍有

\[ k^2 (x - x_0)^2 + k^2 y^2 = 1 \]

所以轨迹为一个圆，形状和大小与初始条件有关。

比如，$F(x,y,y') = x y (y')^2$

\[ \frac{\partial F}{\partial y} = x (y')^2, \quad \frac{\partial F}{\partial y'} = 2x y y', \quad \frac{d}{dx} \frac{\partial F}{\partial y'} = 2y y' + 2x (y')^2 + 2x y y'' \]

\subsection*{3.3 测地线（曲面上两点之间距离最短的一条线）}

我们现在寻找一个球面上两点之间最短距离，球半径为$R$。

球坐标下，无穷小位移路程 $ds_\theta = R d\theta$

若改变$\varphi$，则 $ds_\varphi = R \sin\theta d\varphi$，在方向上，$ds_\theta, ds_\varphi$互相垂直，所以

\[ ds^2 = R^2 d\theta^2 + R^2 \sin^2\theta d\varphi^2 \]

我们可以选择$\varphi$或$\theta$作为积分的变量，以用$\varphi$为例

\[ S = R \int_a^b \sqrt{(\theta')^2 + \sin^2\theta} \, d\varphi \]

其中$\theta$和$\theta'$是$\varphi$的函数，

\[ \theta' = \frac{d\theta}{d\varphi} \]

第 11 页

(1)情况下，根据欧拉方程

\[ \frac{\partial F}{\partial \theta} - \frac{d}{d\varphi} \frac{\partial F}{\partial \theta'} = 0 \quad \text{其中} \quad F = \sqrt{(\theta')^2 + \sin^2 \theta} \]
\[ \frac{\partial F}{\partial \theta} = \frac{\sin\theta \cos\theta}{\sqrt{(\theta')^2 + \sin^2 \theta}}, \quad \frac{\partial F}{\partial \theta'} = \frac{\theta'}{\sqrt{(\theta')^2 + \sin^2 \theta}} \]
\[ \frac{d}{d\varphi} \frac{\partial F}{\partial \theta'} = \left( (\theta')^2 + \sin^2 \theta \right)^{-3/2} \sin\theta \left( \sin\theta \cdot \theta'' - \cos\theta (\theta')^2 \right) \]
\[ \frac{d}{d\varphi} \left( \frac{\partial F}{\partial \theta'} \right) = \frac{\theta''}{\sqrt{(\theta')^2 + \sin^2 \theta}} - \frac{(\theta')^2 \theta''}{\left( (\theta')^2 + \sin^2 \theta \right)^{3/2}} - \frac{\sin\theta \cos\theta (\theta')^2}{\left( (\theta')^2 + \sin^2 \theta \right)^{3/2}} \]
\[ = \left( (\theta')^2 + \sin^2 \theta \right)^{-3/2} \left[ \theta'' \sin^2 \theta - \sin\theta \cos\theta (\theta')^2 \right] \]

所以

\[ \frac{\sin\theta \cos\theta}{\sqrt{(\theta')^2 + \sin^2 \theta}} - \frac{\theta'' \sin^2 \theta - \sin\theta \cos\theta (\theta')^2}{\left( (\theta')^2 + \sin^2 \theta \right)^{3/2}} = 0 \]
\[ \frac{\sin\theta \left( 2(\theta')^2 \cos\theta + \cos\theta \sin^2 \theta - \sin\theta \theta'' \right)}{\sqrt{(\theta')^2 + \sin^2 \theta}} = 0 \]

令 \( f(\theta) = \cot\theta \implies \theta' = -f' \sin^2 \theta \)

\[ \theta'' = -f' \sin^2 \theta + 2(f')^2 \sin\theta \cos\theta \]
\[ \sin^4 \theta \left( f + f'' \right) = 0 \]

由此可得

\[ \cot\theta = A \sin(\varphi - \varphi_0) = A \sin\varphi + B \cos\varphi \]
\[ \cos\theta = A \sin\theta \sin\varphi + B \sin\theta \cos\varphi \]

两边乘 \( r \) 得 \( z = A x + B y \)，即此限制必过球心。

第 12 页

所以在球面上，两点之间距离的极大或极小值必是在大圆线上。

(2)

我们重新把 $S$ 写为

令

即

曲线为过球心的平面与球面的切割线，即为大圆。

第 13 页

第 15 页

从a到b的用时为

\[ t = \int \frac{ds}{V} \]

其中

\[ ds = \sqrt{dx^2+dy^2} = \sqrt{1+(y')^2} dx = \sqrt{1+(x')^2} dy \]

根据机械能守恒

\[ E = \frac{1}{2}mv^2 + mg(-y) = 0 \]

得

\[ v = \sqrt{2gy} \]
\[ t = \int \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}} dx \quad \text{或} \quad t = \int \frac{\sqrt{1+(x')^2}}{\sqrt{2gy}} dy \]

采用后一种方案

\[ F = \frac{\sqrt{1+(x')^2}}{\sqrt{2gy}} \]
\[ \frac{\partial F}{\partial x} = 0 \implies \frac{d}{dy}\left( \frac{\partial F}{\partial x'} \right) = 0 \implies \frac{\partial F}{\partial x'} = k \quad \text{常数}. \]
\[ \frac{\partial F}{\partial x'} = \frac{1}{\sqrt{2gy}} \cdot \frac{x'}{\sqrt{1+(x')^2}} = k \quad \implies \quad \frac{1}{2gy} \cdot \frac{x'^2}{1+x'^2} = k^2 \]

得

\[ x' = \frac{\pm k \sqrt{2gy}}{\sqrt{1 - 2k^2 g y}} = \pm \sqrt{\frac{y}{a - y}} \quad \text{其中} \ a = \frac{1}{2k^2 g}, \ \text{取正值}. \]

抛物面方程为 $z = A(x^2 + y^2)$，其中 $A$ 为常数，求测地线方程，设已知该测地线过点 $(x,y)_0=(x_0,0)$，且满足 $\left(\frac{dy}{dx}\right)_0 = 0$，该测地线能否回到原点相同点？

弧长元素：

\[ L = \int ds = \int \sqrt{1 + 4A^2 r^2 + r^2 \left(\frac{d\theta}{dr}\right)^2} dr \]

\[ \frac{\partial F}{\partial \theta'} = \frac{r^2 \theta'}{\sqrt{1 + 4A^2 r^2 + r^2 (\theta')^2}} = k \]

\[ \frac{dy}{dx} = \frac{(dr)\sin\theta + r\cos\theta d\theta}{(dr)\cos\theta - r\sin\theta d\theta} = \frac{\sin\theta + r\cos\theta \theta'}{\cos\theta - r\sin\theta \theta'} \]

3.

在2维平面内，运用极坐标，证明直线距离最短

解:

距离与路径关系为

\[ I[\ ] = \int \sqrt{(dx)^2 + (dy)^2} \]

在极坐标下，$x = r\cos\theta$，$y = r\sin\theta$

\[ dx = -r\sin\theta \, d\theta + \cos\theta \, dr, \quad dy = r\cos\theta \, d\theta + \sin\theta \, dr \]
\[ (dx)^2 + (dy)^2 = (dr)^2 + r^2 (d\theta)^2 \]
\[ I[\theta(r)] = \int \sqrt{(dr)^2 + r^2 (d\theta)^2} = \int \sqrt{1 + r^2 (\theta')^2} dr, \quad \theta' = \frac{d\theta}{dr} \]

令 $F = \sqrt{1 + r^2 (\theta')^2}$，

欧拉方程：$\frac{\partial F}{\partial \theta} - \frac{d}{dr} \left( \frac{\partial F}{\partial \theta'} \right) = 0$

所以 $\frac{\partial F}{\partial \theta'} = \frac{r^2 \theta'}{\sqrt{1 + r^2 (\theta')^2}} = C$，

\[ (\theta')^2 = \frac{C^2}{r^4 - C^2 r^2} \]

得 $d\theta = \pm \frac{C}{\sqrt{r^4 - C^2 r^2}} dr$

\[ \theta - \theta_0 = \pm \int \frac{C}{r \sqrt{r^2 - C^2}} dr \]

令 $r = \frac{C}{\sin\varphi}$，

\[ dr = \frac{-C \cos\varphi}{\sin^2 \varphi} d\varphi, \quad r \sqrt{r^2 - C^2} = \frac{C^2}{\sin\varphi} \sqrt{\frac{1 - \sin^2 \varphi}{\sin^2 \varphi}} = \frac{C^2 \cos\varphi}{\sin^2 \varphi} \]
\[ \theta - \theta_0 = \pm \int \frac{ - \frac{C^2 \cos\varphi}{\sin^2 \varphi} }{ \frac{C^2 \cos\varphi}{\sin^2 \varphi} } d\varphi = \pm \int d\varphi = \varphi - \varphi_0 \]

所以 $r = \frac{C}{\sin\varphi} = \frac{C}{\sin(\theta - \theta_0)}$，得 $r \sin(\theta - \theta_0) = C$

展开得：$r \sin\theta \cos\theta_0 - r \cos\theta \sin\theta_0 = C$，即 $x \cos\theta_0 - y \sin\theta_0 = C$，这是直线方程。
